# Lyrics Finder

A web-based lyrics workspace designed for searching,
viewing, synchronizing and exporting song lyrics.

## Features

- Song and artist search
- Synced lyrics support
- Plain lyrics support
- Manual lyric synchronization
- Audio preview
- LRC generation
- Copy lyrics/LRC
- Download LRC files
- Responsive interface
- Search and error states

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- REST API

## How It Works

1. Search for a song.
2. Select a result.
3. View synchronized lyrics when available.
4. For plain lyrics, upload the audio file.
5. Synchronize each lyric line using the keyboard.
6. Export the result as an LRC file.

## Project Goal

The project was built as a practical lyrics-processing
workspace and portfolio project.
